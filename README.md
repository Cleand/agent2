# 기프트코 책임배송 홈 — 로컬 구현

슈카를 중심으로 한 책임배송 캠페인과 기업·기관 구매자의 조건별 탐색을 결합한 반응형 홈입니다. Anthropic의 [frontend-design 스킬](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)을 적용했습니다. 원본 서비스는 변경하거나 배포하지 않았습니다.

## 실행

Windows에서는 `Start-Local.cmd`를 실행하고 http://127.0.0.1:4173/ 에 접속하세요. Node.js 20 이상이 필요하며, 현재 작업 환경의 Codex 내장 Node도 자동으로 찾습니다.

다른 환경에서는 이 폴더에서:

```sh
npm start
```

의존성 설치나 빌드가 필요하지 않습니다. 종료는 실행 창에서 Ctrl+C입니다. HTML을 파일로 직접 열면 ES 모듈이 차단될 수 있으므로 로컬 서버를 사용하세요.

## 구현한 동선

1. 슈카 이미지와 “행사 날짜는 정해져 있으니까. 기프트코 책임배송” 캠페인 → 선물 탐색/책임배송 설명.
2. 상품명·예산·수량·행사일 입력 → 목적/카테고리별 탐색 → 인쇄 필터와 가격/제작 기간 정렬.
3. 상품 카드에서 최소 수량, 수량 기준 단가, VAT, 제작 기간, 인쇄/포장 확인.
4. 최대 3개 상품 비교, 브라우저에 유지되는 찜, 수량별 가격표와 참고 금액 계산.
5. 실제 기프트코 상품 상세로 이동해 옵션 선택·주문.
6. 책임배송 적용 조건 확인 → 상담 내용 작성 → 이메일 앱/전화로 전달. 자동 접수로 오인하지 않도록 현재 상태 표시.
7. 기존 공식 영상·후기·기획전·브랜드·혜택 페이지 연결.

PC는 최대 1,240px 콘텐츠와 5열 상품, 모바일은 2열 상품과 하단 탐색 메뉴로 구성했습니다. 검색 결과 없음, 최소 수량 미달, 지난 행사일, 저장 공간 오류, 클립보드 오류도 처리합니다. 자동 슬라이드·자동 재생·진입 팝업은 없습니다.

## 파일 구성

| 파일 | 수정 범위 |
|---|---|
| `dist/index.html` | 헤더, 슈카 캠페인, 조건 검색, 모바일 메뉴 |
| `dist/sections.js` | 목적/카테고리, 상품 영역, 책임배송, 가이드, 후기, 기획전, 푸터 |
| `dist/styles.css` | 디자인 토큰, PC/모바일 레이아웃, 카드, 모달 |
| `dist/app.js` | UI 상태, 필터, 비교, 찜, 상담, 접근성, 이벤트 |
| `dist/catalog.js` | 10개 상품 스냅샷과 가격/필터 로직 |
| `dist/icons.js` | SVG 아이콘 |
| `dist/assets/` | 기존 기프트코 이미지, 슈카 사진, Pretendard |
| `server.mjs` | 127.0.0.1에만 바인딩하는 로컬 서버 |
| `tests/catalog.test.mjs` | 가격 및 필터 로직 테스트 |
| `asset-sources.json`, `catalog-sources.json` | 자산·상품 출처 |
| `DESIGN.md`, `IMPLEMENTATION.md`, `QA.md` | 디자인 결정, 운영 연결 작업, 검증 결과 |

## 데이터와 운영 범위

상품 10개의 가격표·최소 수량·제작 기간은 2026-09-25 기존 스테이징 상품 상세에서 확인한 정적 데이터입니다. 실시간 재고·배송 가능일·쿠폰·결제·계정 API는 연결하지 않았습니다. 모든 상품을 대표하는 검색 엔진도 아닙니다. 기존 서비스의 구매 흐름으로 연결하는 프런트엔드 구현입니다.

정확히 공개된 수량은 해당 가격을 표시합니다. 중간 수량은 직전 가격 구간의 **참고 단가**로 표시하고 확정 견적이 아님을 알립니다. 제작 기간으로 도착일을 계산하지 않습니다. 목적별 추천은 편집 분류이며 판매순위나 슈카의 상품 추천을 의미하지 않습니다.

책임배송의 구체적인 보상액·면책·적용 조건은 제공되지 않아 만들어 넣지 않았습니다. 운영자가 확정한 정책과 API를 연결할 위치는 `IMPLEMENTATION.md`에 정리했습니다.

## 이미지와 사용권

상품·카테고리·기획전·공식 캠페인 이미지는 기존 기프트코 사이트에서 가져왔습니다. 슈카 메인 사진은 [아츠로 공개 프로필](https://www.artsro.com/right/enter_view.html?CatNo=129&GoIdx=2992)을 사용했습니다. Google 이미지 검색은 접근 확인 화면으로 진행할 수 없어 웹 이미지 검색으로 찾은 공개 프로필 사진을 사용했습니다. 사진을 AI로 변형하지 않았으며 CSS로 배치했습니다.

이 사진의 광고용 사용권은 확인되지 않았습니다. 공개 운영 시 기프트코가 사용 권한을 확보한 공식 모델 원본으로 교체하세요. 출처 표기 자체가 사용권을 부여하지 않습니다. Pretendard는 SIL OFL 1.1이며 `FONT-LICENSE.txt`를 포함했습니다.

## 검증 실행

```sh
npm run check
```

브라우저 수동 검증 결과는 `QA.md`를 참고하세요. 전환율 개선은 검증 전 가설이며, 성과 수치를 임의로 제시하지 않았습니다.
